# 🔐 Password Generator (Desktop App)

This project is a **desktop application for generating secure passwords** using Python and Tkinter.  
The app allows you to customize password length, include different character sets (lowercase, uppercase, digits, symbols), copy them to the clipboard, and save them to a file.  

🚧 **Status: Under Construction** 🚧  
Currently, the project is being developed and improved. Future updates will include a better UI, customization options, and an executable build for Windows.
